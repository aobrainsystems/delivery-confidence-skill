# delivery-forecast (Rovo skill)

Open-source Agent Skill used by the **Delivery Confidence for Jira** Forge app. It teaches a Rovo agent (or any MCP client connected to the app's `rovo:mcp` server) when to call the app's five tools and how to read their results.

- `SKILL.md` — the skill (Agent Skills spec frontmatter + instructions)
- `references/` — scoring rules and forecasting method
